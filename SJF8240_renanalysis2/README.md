# SJF8240_renanalysis2

Numbered, reviewed SJF8240 analysis scripts in execution order. Start with [SCRIPT_GUIDE.docx](SCRIPT_GUIDE.docx) or [SCRIPT_GUIDE.md](SCRIPT_GUIDE.md).

The usual route reuses existing graphs:01 →05 →06 →07 →08 →12 →13. Rebuild options and the separate09–11 full-frame E2 route are explained in the guide. Running07 starts new GNN fitting; no fitting was started while this folder was prepared.

Original data/results remain in SJF8240_reanalysis. Supporting code is under _workflow/, configuration under config/, new outputs under outputs/, and earlier report snapshots under reference_results/.
