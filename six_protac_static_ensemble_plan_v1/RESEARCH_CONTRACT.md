# Scientific requirements for the six-compound static campaign

Latest user instruction: publishable-quality data, no MD, pocket-constrained pRosettaC screening and later GNN. No publication outcome is guaranteed by software checks.

1. All six purchased Tocris/Bio-Techne structures use their verified stereochemical molecular graphs. Historical SJF8240 connectivity is a distinct branch, never silently relabeled supplier chemistry.
2. ATP-pocket placement is a justified starting hypothesis for each compound-target pair, not proof all six bind all kinases. Validate the exact conjugated head, atom mapping, pocket fit, state and exit vector. Keep failed/uncertain transfers explicit.
3. The existing repaired baseline holds bound-head coordinates fixed during full-linker construction/scoring. This is a declared approximation, not unrestricted flexible ligand redocking or thermodynamic sampling. The native-head contract is at most0.05Å displacement in the engine; relaxing that contract would require a separately benchmarked protocol, not an undocumented override. Protein orientation/local refinement and linker sampling remain separate stages.
4. Preserve whole E3/kinase chains for clash assessment, use actual VHL identity, and report construct boundaries and missing lysines. Domain-only screening does not establish full-protein ubiquitination accessibility. Wider context checks on shortlisted candidates use static structures only.
5. Known-structure recovery is evaluated using prespecified metrics and ranked outputs. The current5Åtarget-CA/0.5residue-contact gate is an exploratory coarse gate, not DockQ/CAPRI certification or near-atomic recovery. Report raw continuous metrics; stronger standardized structural evaluation and additional independent controls are needed for publication claims.
6. One successful pose in one reference is not robust recovery. Assess seeds, sampling depth, valid cluster diversity, ranking and uncertainty without choosing thresholds from desired degradation labels. Keep null/failed outcomes and expensive-budget sensitivity separate from common-budget primary comparisons.
7. Treat productive fractions as fractions under a documented computational sampling scheme. Neither cluster populations nor pose counts are equilibrium probabilities. Lysine burial, exposure and E2/Ub distances are separate candidate features with distinct denominators.
8. Degradation and binding labels are compound-, assay- and context-specific. Unknown SIK3/RPS6KB2 stay unlabelled. Docking failures are never biological negative labels. Missing/unmeasured kinases do not increase supervised sample size.
9. Freeze preprocessing/splits before GNN evaluation; group all target poses/variants across compounds in held-out-target evaluations and assess held-out compounds separately. Fit normalization, class weights and thresholds on training folds only. Report all seeds and per-target scores rather than the best AUROC.
10. Preserve immutable inputs/source hashes, complete rejection accounting, raw scores, failed attempts, controller receipts and independent verification. Bounded remote benchmarks are permitted while scientific production release remains pending. No full kinome launch until structural/resource evidence supports it. Keep licensed runtime components private and source/report checkpoints on GitHub.

Current evidence: old seed42small-budget MZ1 has0/62retained poses passing the coarse frozen recovery gate; GSK215 has1/3, with its top-ranked pose failing. This does not qualify the whole docking pipeline as validated. A bounded Ernie reference/resource pilot tests the proposed smaller first-pass budget; it does not substitute for independent biological validation.

11. The engine's retained-pose QC currently includes a coarse minimum-distance screen. It is insufficient by itself for final structural acceptance. Apply an independent, atom-type-aware steric review calibrated against deposited reference structures before accepting any campaign pose for final rankings or GNN graphs. The MS143 review demonstrates why: an initial candidate passed the1.5Åscreen but had1.39ÅvdWoverlap; it was rejected. Do not change the frozen remote pilot during execution; stricter analyses are separate, versioned derivatives.
